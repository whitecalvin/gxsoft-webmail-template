# Gmail OAuth 안내 마법사

관리자 Gmail OAuth 페이지의 Google Cloud Console 안내 제목 옆에 ‘단계별 설정 마법사’ 버튼을 추가했다.

- 기존 공통 Modal·DialogActions·Button·Tooltip 재사용. 6단계 이전/다음/단계 번호 이동, 닫기·Escape, 단계 변경 시 제목 포커스 및 본문 스크롤 초기화.
- 기존 상세 안내의 단계 본문/콜백 매핑을 `GmailOAuthGuideStep`으로 추출하여 인라인 안내와 팝업이 동일한 정보를 사용한다.
- 현재 공개 HTTPS 입력에서 원본과 콜백을 전달한다. 비어 있는 주소는 입력 필요 안내를 표시한다.
- 마법사는 안내용이며 설정 저장·Google 인증·운영 변경을 실행하지 않는다. 마지막 버튼도 ‘완료’ 대신 ‘안내 닫기’로 표시한다. 비밀키를 전달하지 않고 토큰·브라우저 영속 저장도 없다.
- 공통 모달이 포커스 가둠·복귀·스크롤 잠금을, 공통 DialogActions가 OS별 버튼 순서를 관리한다. 새 모달/확인 창 시스템을 만들지 않았다.

검증: 새 마법사와 추출된 안내 회귀(개발/production) 통과, 변경 범위 ESLint 통과. 컴파일·TypeScript·432페이지·trace를 포함한 프로덕션 빌드 종료 0, BUILD_ID `X6ayuzEZYSSHWN6mdGBSQ`. 변경 없는 API·Google 콜백 테스트는 반복하지 않았다. 이후 문서·화면 증거만 기록하여 재빌드하지 않는다.

실제 관리자 GUI에서 열기 → 다음 3회 → 4단계 콜백 표시 → 이전/다음 → Tab 포커스 모달 내부 유지 → 6단계 직접 이동 → Escape 닫기와 실행 버튼 포커스 복귀를 확인했다. 가로 넘침 없음. 화면 증거 `admin-gmail-oauth-wizard-20261014.jpg`. 주소 입력은 미저장 초안이며 설정 저장·Google 동의·운영 배포는 수행하지 않았다.
