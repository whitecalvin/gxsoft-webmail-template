# 저장된 초안 닫기 변경 감지

- 기존 닫기 조건은 hasContent여서 저장된 초안을 수정하지 않아도 확인창을 표시했다. savedDraftChanged로 저장된 원본과 주소·제목·본문·HTML·첨부를 비교한다. 새 메일은 기존 내용 존재 기준을 유지한다. 미확정 저장/발송 결과와 실패 업로드는 확인창을 유지한다.
- 초기 편집기 HTML 정화는 사용자 변경으로 취급하지 않고 정화된 HTML을 비교 기준에 반영한다. 실제 입력과 형식 전환 후에는 기준을 바꾸지 않는다. 정화/첨부 CID 보존 정책을 끄지 않았다.
- 합성 검사: 원본/되돌린 내용, 주소 공백, 편집기 전용 첨부 메타데이터는 변경 아님. 수신자·발신자·참조·숨은참조·제목·본문·HTML·첨부 변경은 감지한다. 작성/임시저장 실제 핸들러의 중복 요청·미확정 결과·업로드 잠금·확인창 busy 보호 회귀 검사 및 변경 파일 ESLint 통과.
- 실제 UI: 이전 검수에서 생성한 QA 초안 한 통만 계속 작성으로 열었다. 수정 없이 닫기 후 dialog0, 본문을 로컬 v3로 수정 후 dialog2(작성창+공통 확인창), 계속 작성 선택 후 저장된 v2 본문으로 되돌리고 닫기 후 dialog0을 확인했다. QA 목록 한 통, 콘솔 error0. 저장·발송·첨부 업로드·삭제는 실행하지 않았으며 임시 탭을 닫았다.
- saved-draft-close-confirm-20261010.png는 본문 변경 시 표시된 공통 확인창만 기록한다. 기존 사용자 메일의 내용은 산출물에 포함하지 않는다.
- diff-check의 ComposeModal.tsx 기존 공백 줄 경고는 이번 변경과 무관한 내용으로 보존했다. 계정 전환·복잡한 HTML/CID 실데이터의 모든 닫기 동작까지 증명하는 검수는 아니다.
- 빌드62259/22289는 업로드 전 선택 필드(blobId/type)와 비교 타입의 불일치로 TypeScript 단계에서 중단됐다. 실제 Attachment 인터페이스를 확인해 비교 타입을 수정했고 tsc60216 exit0을 확인했다. 프로덕션 산출물 완성은 build7873에서 재개한다. 버전·태그·서버 설정은 변경하지 않는다.
- 최종 build7873 exit0: 컴파일·TypeScript·393페이지 생성·최종 빌드 마무리 통과. 이후 변경은 검수 문서만이므로 앱 검증을 반복하지 않는다.
