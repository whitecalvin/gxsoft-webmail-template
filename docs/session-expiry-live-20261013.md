# 현재 세션 실제 만료 검증 — 2026-10-13

사용자가 현재 세션만 최대2분 뒤 만료시키는 서버 준비·제한된 재시작·검증을 승인하고 current=true UUID를 직접 제공했다. 서버 채팅에서 해당 대상과 기존 정책 보존을 확인하고 한시적 승인을 준비했다.

개발용 한국어 UI는 제품 메뉴에 등록하지 않는다. 서버 액션은 production 차단, Origin/Host 일치, 서버 전용 토큰, 정확히 하나인 current 세션 일치, 명시적 확인을 요구한다. 빈 본문 POST는 한 번만 실행하며 불명 결과는 재전송하지 않는다. 응답은 testOnly와 120초 경계 검증 후 정규화한 두 시각만 노출한다. 공통 ConfirmDialog를 사용했다.

- 실제 단일 제출 receipt: serverTime `2026-10-13T03:40:42.718Z`, expiresAt `2026-10-13T03:42:42.718Z`.
- 만료 시각 이후 정상 페이지 새로고침에서 `/ko/login`으로 전환되고 로그인 필드가 표시됐다. 로그아웃은 실행하지 않았다.
- 다른 세션·메일·MFA·전역 정책 변경과 직접 DB 변경은 하지 않았다. 서버 채팅은 전용 승인 환경값 원복·제한된 재시작 완료, 시험 경로404/준비 상태200, 기존 환경·TOML·원격관리 설정 보존을 보고했다. 추가 POST·DB 변경은 없었다.
- 실제 증거: [요청 receipt](session-expiry-requested-20261013.jpg), [만료 후 로그인](session-expired-login-20261013.jpg). 검수용 탭은 닫았으며 사용자가 연 탭은 유지했다.

## 변경 검증

신규 액션/실패 경계/UI 검사4개 통과. receipt 정규화의 테스트 예상값만 수정한 뒤 실패했던 검사1개만 재개했다. 전체 lint 종료0, 운영 빌드420페이지 종료0(BUILD_ID `KhKFbxcsLEfFZf_K5DUEs`), 변경 diff 공백 검사 통과. 번역·다른 앱 입력은 바뀌지 않아 관련 검사를 반복하지 않았다.

현재 세션의 승인된 실제 시간 만료와 접근 차단을 확인한 것이며, 모든 MFA·갱신 토큰·타 계정·자동 만료 안내 조합 또는 전체 제품 수용의 완료는 아니다. 재로그인은 사용자가 수행한다.
