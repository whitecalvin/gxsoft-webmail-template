# 메일 목록 컨텍스트 메뉴의 메일 규칙

## 구현

- 데스크톱 우클릭/더 보기와 모바일 액션 시트가 공유하는 메뉴에 `메일 규칙 만들기`를 추가했다.
- 현재 계정의 기존 규칙을 읽은 후 선택한 메일의 발신자와 일치하는 비활성 초안을 기존 규칙 편집기에 추가한다. 기존 규칙은 보존한다.
- 초안 기본 동작은 `keep;`이다. 실제 처리 동작과 활성 상태는 편집기에서 사용자가 변경하고 전체 규칙 저장을 확인해야 서버에 반영된다.
- 발신자를 URL, 브라우저 저장소 또는 로그로 전달하지 않는다. Sieve 문자열을 이스케이프하고 제어 문자·잘못된 주소를 거부한다.
- 50개 제한, 재조회 시 초안 중복 생성 방지, 계정 전환 시 창 닫기, 저장 중 닫기 방지, 미저장 변경 취소 확인을 적용한다.

## 검증 체크포인트

- 개발 검사 135개 통과: 먼저 실행한 관련 3개 결과를 재사용하고 나머지 132개를 한 번 실행했다.
- 관련 운영 모드 검사 2개 통과: 발신자 초안/컨텍스트 연결, 중복 저장·미확정 저장 보호.
- 전체 ESLint 및 10개 언어 키/사용 검사 통과(2989키, 1161개 리터럴 호출).
- Turbopack 빌드는 CSS 하위 Node 프로세스 연결 단계에서 실패했다. 같은 빌드 단계만 제한 밖에서 재개했으나 동일 오류가 발생했다. 앱 소스/개발 서버 설정 변경 없이 Next.js 제공 Webpack 운영 빌드로 검증을 재개했다.
- 별도 `.next-folder-drag` Webpack 운영 빌드 종료 코드 0: 컴파일, TypeScript, 380페이지 생성 및 최종 최적화 통과. 실행 중인 `.next-secure-dev` 개발 서버 출력은 사용하지 않았다.

## 실행하지 않은 작업

실제 계정 규칙 저장·변경, 로그인 브라우저 수동 검사, 운영 배포, 서버/DB 설정 변경, 커밋·푸시는 실행하지 않았다. 합성 검사 결과는 실제 서버 저장 왕복이나 모바일 수동 검증 완료를 의미하지 않는다.
