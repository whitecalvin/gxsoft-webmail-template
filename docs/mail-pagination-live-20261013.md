승인된 현재 계정의 목록만 조회했다. 메일 행 클릭·상세 열기·읽음 변경·플래그/이동/삭제·발송은 수행하지 않았다. Computer Use 스킬의 실제 UI를 이용했고 API 토큰/쿠키 추출이나 직접 서버·DB 조회는 하지 않았다.

DOM에 표시된 각 행의 접근성 이름과 datetime을 세션 메모리 안에서 비암호학적 fingerprint로 비교했다. 원문·발신자·제목·fingerprint 값은 보고서/로그/스크린샷에 저장하지 않았다. 두 페이지 각각 fingerprint50개가 서로 달랐고 페이지 간 중복0, 첫 페이지 복귀 후 순서까지 같은50개였다. 이것은 표시된 행/순서의 관찰이며 JMAP ID·본문·전체 498통의 정합성이나 충돌 불가능성을 입증하는 검사는 아니다.

수집된 콘솔 warning/error는0개였다. 사용자가 연 탭은 변경하지 않았고 임시 검수 탭은 닫았다. 이 작업은 앱 입력을 바꾸지 않아 앞선 관련 앱 검사/빌드를 중복 실행하지 않았으며 문서 diff 공백만 검사했다.

신규 첨부/초안 추가 발송, MFA·실제 만료, 외부 계정 인증/worker 및 운영 변경 검증은 별도 승인/대상 확인이 남아 있다. 전체 목표는 미완료다.
