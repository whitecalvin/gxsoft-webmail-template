# 검색형 편지함 아이콘 모달

## 적용

- 기존 시스템/사용자 편지함 아이콘 변경 드롭다운을 공통 모달로 교체했다.
- `lucide-react@1.41.0` 등록 목록 2,066개에 `@phosphor-icons/react@2.1.10` 아이콘 1,512개를 추가했다. 이모지는 `@emoji-mart/data@1.2.1`의 native 데이터에서 피부색 변형을 포함한 3,395개 항목을 제공한다. 외부 CDN을 사용하지 않는다.
- 패키지 탭, 검색 필드, 선택 상태 표시, 아이콘 그리드, 기본값 복원, 취소를 제공한다. 영문 아이콘 이름과 메일/폴더/별/보안 등 흔한 한국어 키워드를 검색한다.
- 표시 개수는 80개씩 늘어나며, 필요한 아이콘만 동적으로 로드한다. 아이콘 로드가 지연되거나 실패할 때 자리 표시자를 제공하고, 검색 변경/모달 닫기 후 늦은 응답은 무시한다.
- `lucide:<name>`, `phosphor:<name>`, `emoji:<id>` 값을 현재 계정/편지함별 기존 브라우저 저장소에 저장한다. 기존 8개 아이콘 값은 그대로 읽어오고, 설치된 카탈로그에 없는 값은 기본값으로 처리한다. 생성 유형에 따른 폴더/메일 기본 아이콘 및 설정의 전체 초기화도 유지한다.
- 검색 필드 자동 포커스, 공통 모달의 Tab 포커스 제한/닫은 후 복귀, Escape의 모바일 메뉴 전파 차단, 44px 이상 터치 영역과 테마 변수를 적용했다.

노션의 아이콘 클릭 후 선택 메뉴를 여는 흐름을 참고했다. 이모지를 추가했지만 업로드·무작위 선택까지 복제한 기능은 아니다. 참고: https://www.notion.com/help/guides/page-icons-and-covers

## 추가 패키지·이모지 검증

- 설치 패키지에서 목록과 개별 정적 import 경로를 기계적으로 생성하는 `scripts/generate-extra-mailbox-icons.mjs`를 추가했다. 패키지 버전 변경 시 재생성해야 한다.
- 패키지별 검색·선택 상태를 구분한다. 이모지는 영어 이름·키워드·이모지 문자 및 흔한 한국어 키워드로 검색하며, 기기의 native 글꼴로 표시해 운영체제에 따라 모양이 다를 수 있다.
- 개인/시스템 편지함 설정 유지·리셋과 세 탭의 선택·검색·제한된 그리드 검사 2/2 통과. 추가 검사에서 설치 데이터의 모든 이모지 변형 일치, Phosphor import 목록 일치, 실제 Acorn SVG 및 이모지 렌더링을 확인했다.
- 변경 파일 ESLint 및 10개 언어 카탈로그 2,957개 키/ICU 검사 통과. `.next-icon-packages-emoji` 독립 프로덕션 빌드에서 TypeScript와 378개 페이지 생성 통과. 그 후 테스트 스크립트만 보강해 앱 빌드는 반복하지 않았다.
- 실제 데스크톱에서 Phosphor acorn 검색 결과 SVG 한 개를 확인했다. 모바일 390×844에서 이모지 grinning 검색·렌더링을 확인했고 모달은 358×514, 좌우 넘침 없이 화면 안에 표시됐다. 수집된 콘솔 error는 0개였다.
- 브라우저 검증에서는 저장 버튼을 선택하지 않아 사용자의 실제 편지함 아이콘 설정을 바꾸지 않았다. 실제 선택 저장·계정 분리·기본값 복원은 위 컴포넌트 검사 증거이며, 서버 동기화 기능은 추가하지 않았다.

참고: https://github.com/phosphor-icons/react, https://github.com/missive/emoji-mart

Lucide의 이름 기반 로딩 계약과 빌드 시 전체 모듈을 분석하는 특성을 확인했다. 참고: https://lucide.dev/guide/react/advanced/dynamic-icon-component

## 증거

- 영향 검사 4/4 통과: 개인 아이콘 설정, 새 검색 모달, 개인 편지함 UI, 생성 응답 클라이언트 계약.
- 카탈로그가 실제 설치 패키지 등록 목록과 정확히 일치하는지 검사했다. 한국어/영문 검색, 잘못된 패키지·이름 거절, 10개 언어의 실제 모달 렌더, 초기 80개 제한/더 보기, 선택/기본값 복원/portal/Escape를 검사했다.
- 변경 파일 ESLint 및 10개 언어 2,955개 키·ICU 검사 통과. 테스트 헬퍼의 unused 경고는 헬퍼만 수정하고 해당 테스트/ESLint만 재개했다.
- 독립 `.next-mailbox-icon-picker` 프로덕션 빌드: TypeScript 및 378개 페이지 생성 통과. 테스트 헬퍼 수정 후 애플리케이션을 재빌드하지 않았다.
- 로컬 실제 UI: 별도 설정 탭에서 전체편지함 아이콘 변경 모달을 열고 `메일` 검색 결과 21개 및 실제 SVG 21개를 확인했다. Escape 후 버튼 포커스가 복귀했다.
- 모바일 390×844: 메뉴에서 모달을 열고 `folder` 결과 34개/실제 SVG 34개 확인. 모달 크기 358×686, 화면 경계 안에 위치. Escape 후 모달만 닫히고 뒤의 메뉴는 유지됐다. 메뉴 열림 애니메이션 도중 검증 클릭이 잘못된 위치에 전달돼 한 차례 실패했으며, 실제 위치가 안정된 뒤 동일 경로를 확인했다.
- 실계정 아이콘 선택 저장은 하지 않았다. 임시 검증 탭을 닫고 화면 크기 설정을 원복했다. 기존 사용자 탭, 메일 데이터, 운영 서버는 변경하지 않았다.

아이콘은 기존 정책대로 현재 브라우저에만 저장되며 서버/다른 기기와 동기화되지 않는다. 전체 메일 기능의 실서버 수용 검증이나 모든 화면/콘솔 회귀 완료를 뜻하지 않는다.
