# 계정별 시작 편지함 설정 요청

## 사용자 요구

설정 → 받은편지함 및 읽기에서 시작 편지함을 선택한다.

- 마지막 편지함: 기존 계정별 navigation cookie의 선택을 복원한다.
- 받은편지함: 시작 시 inbox를 선택한다.
- 전체편지함: 시작 시 all을 선택한다.

## 서버 계약 확장

기존 GET/PATCH `/api/user/general-settings`의 `settings.inbox.startupMailbox` 필드를 추가한다.

- 허용 값: `last`, `inbox`, `all`.
- 기존 계정 기본값: `last` (현재 복원 동작 유지).
- 기존 저장 JSON에 필드가 없으면 읽기 시 `last`로 정규화한다.
- PATCH는 동일 expectedRevision, 인증 계정 소유권, 세션 세대, no-store, 충돌 보호를 유지한다.
- 다른 값·다른 자료형은 거부한다. 다른 설정과 계정은 변경하지 않는다.
- 새 테이블이 필요한지는 서버 저장 구조에 따라 판단한다. 운영 배포와 DB 변경은 별도 승인 없이 수행하지 않는다.

## 웹메일 연동

- 공통 Select와 저장 바 사용, 10개 언어 번역 제공.
- 서버 snapshot에서 시작 정책을 SSR로 결정해 다른 편지함이 먼저 보이는 깜빡임을 방지한다.
- 마지막 개인 편지함이 삭제되었거나 권한이 없으면 받은편지함으로 복구한다.
- 선택 정책은 최초 시작/새로고침에 적용하며, 일반 메뉴 클릭과 페이지 간 이동 중 사용자 선택을 강제로 덮어쓰지 않는다.
- 서버가 아직 새 필드를 지원하지 않을 때 기존 설정 조회 전체를 실패시키거나 저장 성공처럼 표시하지 않는다.

## 검증

기존 snapshot 호환성, 세 enum 값 저장·조회, 잘못된 입력, 다른 계정 격리, revision 충돌, 마지막 개인 편지함 삭제 후 복구, 최초 SSR 선택을 검증한다. 실제 계정 설정을 바꾸는 저장 검증은 사용자 승인 후 수행한다.
