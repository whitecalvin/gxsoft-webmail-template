# 사이드바 상호작용 검증 — 2026-10-08

## 구현 범위

- 폴더 종류가 명시된 개인 항목만 폴더로 표시하며 종류 미지정 편지함은 편지함 기본 아이콘을 사용한다. 가상 상위 폴더에도 종류 라벨을 표시한다.
- 아이콘 선택은 미리보기이며 적용 버튼에서만 저장한다. 취소는 저장하지 않는다. 저장 중 중복 적용 및 닫기를 막으며 서버 확인 실패는 창을 유지한다.
- 폴더·편지함 이동 손잡이는 마우스와 터치 모두 포인터 캡처로 처리한다. 마우스 손잡이는 기본 HTML 드래그와 경쟁하지 않도록 pointerdown을 처리한다. 이름·행의 기존 HTML 드래그 경로는 유지한다.
- 편지함을 대상 컨테이너로 삼는 이동, 순환 이동, 충돌 및 미확정 상태에서의 변경은 허용하지 않는다.

## 로컬 검증 및 실패 재개

- 최신 앱 입력에서 전체 개발 검사 134개 중 132개가 통과했다. 실패한 두 검사는 테스트 로더의 모듈 연결 누락이었다.
- `test-mailbox-display-settings.mjs`: 삭제된 current-user 대역을 제거하고 실제 mail-shortcuts 모듈을 연결했다.
- `test-settings-header-ssr.mjs`: 실제 DrawerHistory 모듈을 연결했다. SSR에서 브라우저 효과는 실행되지 않는다.
- 첫 실패 게이트인 위 두 검사만 재개하여 2/2 통과했다. 재개 합계 134/134이며, 수정 후 전체를 재실행한 결과라고 주장하지 않는다.
- 변경한 두 검사 파일 ESLint 통과. 테스트 로더 변경은 앱 빌드 입력이 아니므로 앱 빌드를 재실행하지 않았다.
- 직전 앱 전체 ESLint 및 별도 `.next-folder-drag` 운영 빌드 통과. 포인터 드래그·사이드바 운영 모드 검사 2/2 통과. 아이콘 선택 개발·운영 모드 검사와 10개 언어 키/사용 검사도 통과했다.

## 남은 실검증

실제 사용자 브라우저의 드래그 시작·놓기, 아이콘 서버 저장 왕복, 모바일 레이아웃, hydration 및 콘솔 상태는 위 합성 검사로 입증되지 않는다. 브라우저 검사 시도가 로그인된 페이지의 광범위한 메일 정보 노출 위험으로 차단되어 사용자 승인 대기다. 실제 폴더 이동·계정 설정 변경은 실행하지 않았다. 운영 배포·DB·서버 구성·커밋·푸시도 하지 않았다.

전체 GXWebMail ↔ TASTEMAIL 실서버 연동 목표는 진행 중이다. 이후 사용자 지시인 mock 완전 제거와 현재 전송 경로 확인을 우선하며, 이전 목표에 적힌 mock 유지·7531을 되살리지 않는다.
