# 실제 서버 전용 실행

2026-10-06부터 서비스 실행은 TASTEMAIL 서버 전용이다.

- 시연 로그인·가입·발송, 시연 관리자/일정/연락처/파일/메일 데이터와 모드 선택 분기를 제거했다.
- `GXWEBMAIL_DATA_MODE`는 무시한다. 연결 주소는 서버 전용 `TASTEMAIL_API_URL`로 지정한다.
- 서버 실패와 권한 거부는 기존 오류 경로로 처리하며 시연 데이터로 대체하지 않는다.
- 캘린더·주소록·공유 편지함 목록은 최초 HTML 진입에서 SSR, 이후 내부 이동과 조회/변경은 CSR이다.
- 받은편지함 표시 설정은 브라우저 설정이다. 이를 서버 설정 저장으로 간주하지 않는다.
- 서버에서 지원되지 않는 설정은 미지원 안내를 표시한다. 기능을 구현한 것으로 표시하지 않는다.
- 테스트의 합성 응답·fixture는 운영 모드가 아니며 회귀 검사 목적으로 유지한다.
- 2026-10-07 전송 경계 강화: API 주소는 HTTPS 또는 루프백 HTTP만 허용한다. RFC1918 LAN 평문 HTTP도 요청 전 거부한다. 기존 LAN 주소를 사용할 때는 검증된 HTTPS 또는 로컬 SSH 터널이 필요하며, `.env` 연결 대상은 자동 변경하지 않는다.

검증: 기존 로컬 검사 88개와 새 실제 서버 전용 회귀 검사 1개 통과. 실패한 오래된 모드/화면 fixture만 수정하여 재실행했으며 성공한 검사는 반복하지 않았다. ESLint, TypeScript 및 분리된 `.next-live-only-check` 프로덕션 빌드 통과. Next.js에는 별도의 Debug/Release 단위 테스트 구성은 없으므로 동일한 검사를 두 번 실행하지 않았다.

이번 변경의 실제 로그인·메일 변경·모바일 화면 검증과 원격 배포는 수행하지 않았다. 실행 중인 7540 개발 서버와 메일 서버도 재시작하지 않았다. README의 이전 mock 관련 내용은 역사적 작업 기록이며 현재 실행 계약은 이 문서를 따른다.
