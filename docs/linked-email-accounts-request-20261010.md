# 기본 계정에 추가 이메일 계정 연결

## 확정된 사용자 요구

- 기본 TASTEMAIL 계정 아래에 여러 계정을 등록한다.
- TASTEMAIL 계정뿐 아니라 네이버와 Gmail 외부 계정도 포함한다.
- 공유·위임 편지함이나 발신 별칭과 별개인 연결 계정 기능이다.
- 로그아웃 없이 계정을 전환한다. 연결 정보는 기본 계정 소유로 서버에 저장한다.

## 현 코드의 경계

- 프런트엔드 `lib/tastemail/session.ts`는 로그인 세션 쿠키 하나를 읽는다.
- 공유 편지함의 accountId는 공유 권한 모델이다. 외부 계정 등록으로 재사용하지 않는다.
- 확인한 TASTEMAIL API 라우트와 마이그레이션에는 외부 연결 계정 관리/인증/동기화 계약이 없다.
- 이 문서는 서버 구현 요청 초안이다. API가 구현되었거나 실제 외부 계정이 연결되었다는 뜻이 아니다.

## 서버 구현 요청 범위

1. 인증된 기본 계정 소유의 연결 계정 목록, 등록, 연결 상태 조회, 재인증, 연결 해제 API 및 마이그레이션.
2. Gmail: Google OAuth 2.0 기반 인증 및 갱신. OAuth 앱 설정/리디렉션 URI/필요 권한/검증 상태는 운영자 설정으로 관리한다.
3. 네이버: 사용자가 IMAP/SMTP 사용을 설정하고 발급한 애플리케이션 비밀번호로 TLS 연결한다. 일반 로그인 비밀번호를 요구하지 않는다.
4. 일반 IMAP/SMTP 지원 시 TLS 인증서 검증 필수. 임의 호스트를 받는 기능은 DNS 재해석/리디렉션/사설·루프백·메타데이터 주소 등의 SSRF 위험을 통제한다. 운영자가 승인한 TASTEMAIL 호스트는 별도 정책으로 관리한다.
5. 인증 정보는 서버의 암호화 저장소에서 관리하고 일반 조회 응답/로그/브라우저 저장소에 노출하지 않는다. 연결 해제 시 동기화 작업과 자격 증명을 정리한다.
6. 계정 ID와 원격 메시지 ID를 함께 사용해 목록/본문/첨부/읽음/중요/이동/삭제/임시 저장/발송을 정확한 계정에 귀속한다. 원격 메일을 기본 계정 메일로 오인하거나 기본 서버 발송 경로로 대체하지 않는다.
7. 동기화는 재시작 가능한 체크포인트와 중복 방지, 제한된 배치/동시성, 인증 만료/일시 장애 상태를 갖춘다. 가져오기와 양방향 동기화의 차이를 API 계약에 명시한다.
8. 기본 계정이 연결 계정에 접근할 때마다 서버에서 소유권을 확인한다. 세션 만료/연결 해제/계정 전환 시 이전 계정 데이터와 진행 중 요청이 새 화면에 반영되지 않는다.
9. 읽기/발송/변경 가능 여부를 기능별 capabilities로 제공한다. 외부 사업자가 지원하지 않는 기능은 성공한 것처럼 표시하지 않는다.
10. 연결 해제는 외부 사업자의 원본 메일 삭제와 구분한다. 실제 메일 동기화·발송·삭제 검증 및 운영 배포는 별도 승인 후 수행한다.

## 프런트엔드 후속 작업

- 설정 > 계정: 연결 계정 목록과 계정 추가/재인증/연결 해제.
- 헤더 프로필: 기본 계정과 등록 계정 전환.
- 편지함/메일 검색/본문/첨부/작성: 선택 계정의 데이터와 발송 주소 사용.
- 최초 서버 렌더링에서 계정 목록과 선택 계정을 제공하여 기본 아이콘/계정이 잠깐 보이는 현상을 방지.
- 기존 공통 대화상자, 사용자 정의 툴팁, 입력 필드, 버튼과 디자인 토큰 사용.

## 검증 경계

서버 계약 확정 전 임의 API 호출, 가짜 연결 완료 데이터, 브라우저 비밀번호 저장을 구현하지 않는다. 서버의 소유권 격리·비밀 저장·OAuth 콜백·동기화 재개 회귀 검증이 필요하다. 실제 외부 계정 연결은 아직 수행하지 않았다.

## 2026-10-11 구현 범위

- 서버 계약 `GET/POST /api/user/linked-accounts`, `DELETE /api/user/linked-accounts/{id}`에 맞춰 설정의 목록·주소 등록·연결 해제와 동일 출처 BFF를 구현했다. 목록은 설정 서버 레이아웃에서 초기화한다.
- 서버의 `authenticationAvailable: false` 및 모든 메일 capabilities가 비활성인 계약을 그대로 표시한다. Gmail OAuth, 네이버 인증, 메일 동기화·계정 전환·외부 계정 발송은 아직 구현 범위에 포함되지 않는다. 비밀번호 입력은 제공하지 않는다.
- 등록·해제 응답이 불확실하면 쓰기를 재시도하지 않고, 목록에서 결과를 확인할 때까지 잠근다. 연결 해제에는 공통 확인 창을 사용한다.
- `node scripts/test-linked-accounts.mjs`는 합성 데이터로 계약, BFF, 불확실한 쓰기 결과 확인, 열 개 언어의 목록 렌더링을 검사한다. 실제 계정 등록·해제 또는 외부 원본 메일 변경은 수행하지 않았다.
