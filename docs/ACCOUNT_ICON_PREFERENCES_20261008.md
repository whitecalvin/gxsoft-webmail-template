# 계정별 아이콘 표시 설정 — 2026-10-08

- 헤더 오른쪽 프로필 아이콘은 프로필 메뉴에서 아이콘을 눌러 변경한다. 헤더와 열린 프로필 메뉴에 같은 선택을 표시한다.
- 개인·기본 편지함 아이콘은 기존처럼 로그인 이메일 주소와 편지함 ID로 분리한다.
- 공유 편지함 카드·선택 계정 헤더에는 별도의 아이콘 변경 버튼을 둔다. 편지함 진입 버튼 안에 버튼을 중첩하지 않는다.
- 프로필 저장 키는 `gxmail:account-icon:v1:<normalized-owner>:self`, 공유 대상은 `gxmail:account-icon:v1:<normalized-owner>:<encoded-shared-target>`다. 공유 대상 ID와 로그인 계정이 모두 같을 때만 선택을 재사용한다. 기본값 복원도 대상별이다.
- Lucide·Phosphor·이모지 선택·검색은 기존 공통 선택 창을 사용한다. 표시 설정만 변경하며 인증·계정 정보·공유 권한을 변경하지 않는다.
- 설정은 브라우저 localStorage에 저장하고 크기가 제한된 표시 전용 쿠키로 SSR에 전달한다. 이모지는 지연 모듈을 기다리지 않고 서버 HTML에 표시한다. 기존 저장소만 있거나 쿠키 캐시에서 제외된 설정은 최초 hydration 전 같은 크기의 빈 슬롯을 유지하며 잘못된 기본 아이콘을 먼저 표시하지 않는다.
- 서버 계정 프로필 API 저장이나 다른 기기 동기화 기능은 아니다. 서버·DB·권한 설정과 기존 메일은 변경하지 않았다.

## 검증

- 계정/공유 대상 분리, 저장·초기화·잘못된 값 거부·미인증 변경 버튼 부재 및 실제 React 서버 렌더링의 이모지 HTML 검사 통과.
- 표시 쿠키의 입력 검증·크기 제한·제한된 저장소 검사와 기존 개인/시스템 편지함 아이콘 검사 통과.
- 변경 파일 ESLint, 10개 언어 2,959개 키/ICU 검사, 독립 `.next-account-icons` 프로덕션 빌드 및 TypeScript/378개 페이지 생성 통과.
- 기존 인증을 사용한 별도 `/ko/settings` 탭에서 프로필 메뉴의 변경 버튼과 세 패키지 선택 모달 진입·Escape 복귀를 확인했다. 선택 저장으로 사용자의 현재 아이콘을 바꾸지 않았다.
- 공유 목록 진입의 최초 관찰 시간 초과 후 같은 탭을 재확인하니 `/ko/mailboxes`에서 빈 목록을 표시했다. 실제 공유 카드 변경 UI와 다른 실계정 전환은 이 환경에서 검증하지 못했다. 합성 분리 검사를 실계정 전환 검증으로 확대하지 않는다. 별도 검증 탭만 닫고 사용자 탭을 보존했다.

## 후속 다국어·반응형 검증 시도

- 한국어 프로필 선택 모달에서 패키지 탭 3개·검색 입력 1개·중첩 버튼 0개를 확인했다. 관측된 모달 좌우 경계는 360–920px였고 문서/viewport 너비는 1280px였다.
- 화면 제어 API에 데스크톱 1280×900과 모바일 390×844를 요청했지만, DOM에서 실제 관측된 크기는 계속 1280×720이었다. 모바일로 요청한 두 번째 한국어 관찰도 viewport 1280을 반환했으므로 모바일 통과로 집계하지 않는다. 같은 브라우저의 새 검증 탭에서도 요청 크기 반영을 입증하지 못했다.
- 영어 프로필 버튼 클릭 후 아이콘 변경 버튼 탐색은 시간 초과했다. 이후 실제 화면은 영어 설정 페이지와 닫힌 프로필 버튼을 표시했다. 이 결과만으로 앱 오류·영어 선택 모달 성공·콘솔 무오류를 판정하지 않는다.
- 목표했던 10개 언어×두 viewport 전체 회귀는 미완료다. 재개 시 실제 viewport가 요청 크기와 일치함을 먼저 확인하고 첫 미완료 화면부터 진행한다. 앱 입력 변경이 없어 성공한 단위 검사·언어 검사·프로덕션 빌드는 반복하지 않았다. 두 검증 탭만 닫고 임시 viewport 설정을 해제했다.

## 데스크톱 10개 언어 선택 창 후속 확인

- 별도 탭에서 실제 접근성 상태를 확인하며 en/de/es/fr/it/pt/ja/zh/zh-hant의 프로필 메뉴 → 계정 아이콘 선택 창을 열고 Escape로 복귀했다. 동일 입력의 기존 ko 데스크톱 관찰은 재사용했다. 10개 언어 모두 해당 언어의 모달 제목, 패키지 탭 3개, 검색 입력 1개가 표시됐다.
- 영어는 실제 화면의 버튼으로 선택 창 진입이 확인돼 앞선 탐색 시간 초과를 앱 실패로 판정하지 않는다. 독일어 최초 측정은 접근성 출력 끝의 포커스 요약 행을 검색 입력으로 중복 집계했다. 실제 숫자 ID를 가진 요소 행만 집계하도록 측정을 수정해 입력 1개를 확인했다. 앱 소스 수정은 필요하지 않았다.
- 마지막 수집 warning/error 로그는 0개(최대 100개), hydration 관련 항목도 0개였다. 모든 시간대·필터·화면의 콘솔 무오류를 입증하는 결과로 확대하지 않는다.
- 이 결과는 기본 데스크톱 화면의 진입·표시 구조 검증이다. 모바일, 모든 언어의 픽셀 경계/높이, 아이콘 저장·실계정 전환, 공유 카드, SVG 패키지 초기 SSR 완료를 증명하지 않는다. 모든 아이콘의 첫 표시 지연은 별도 진단에서 아직 남아 있음을 확인했다.
- 실제 아이콘 선택 저장·메일 열기/변경·보안/권한/운영 설정 변경은 수행하지 않았다. 별도 탭을 닫고 사용자 탭을 보존했다. 문서만 갱신해 앱 게이트는 반복하지 않았다.
